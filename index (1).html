همگام‌سازی با گیت‌هاب

با وصل کردن یه توکن گیت‌هاب، هر تغییری که تو اپ میدی خودکار رو ریپازیتوری خودت ذخیره میشه و از هر دستگاهی که همین توکن رو وارد کنی دیتا یکی میمونه.

وضعیت: متصل نیست
چطور توکن بسازم؟
  1. برو به github.com → تنظیمات حساب (Settings) → پایین صفحه Developer settings
  2. Personal access tokens → Fine-grained tokens → Generate new token
  3. در بخش Repository access، گزینه «Only select repositories» رو بزن و فقط همون ریپوی این اپ رو انتخاب کن (نه بقیه سایت‌هات)
  4. در بخش Permissions → Repository permissions، برای Contents مقدار «Read and write» رو انتخاب کن — بقیه رو دست نزن
  5. Generate token بزن، کدی که میده رو کپی کن و همینجا پیست کن

این توکن فقط رو همین گوشی/مرورگرت ذخیره میشه و هیچ‌وقت داخل خود کد یا ریپوی عمومی قرار نمی‌گیره. چون توکن رو فقط به همین یه ریپو محدود کردی، به سایت‌های دیگه‌ت هیچ دسترسی‌ای نداره.
